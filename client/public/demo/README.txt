PHOTOS DE LA CONSULTATION FANTÔME (démo onboarding dermatologue)
=================================================================

La consultation de démonstration "Aminata Test" attend DEUX images ici,
avec ces noms EXACTS :

  1. aminata-face.jpg      → la photo de face (visage entier)
  2. aminata-profile.jpg   → la photo de profil

Ce sont les deux photos que tu as envoyées dans le chat.

Comment faire :
  - Enregistre la photo de FACE sous : client/public/demo/aminata-face.jpg
  - Enregistre la photo de PROFIL sous : client/public/demo/aminata-profile.jpg
  - Commit + push, puis redéploie.

Le dossier de démo affiche aminata-face.jpg. Tant que le fichier n'est pas
présent, l'emplacement photo reste vide (aucune erreur bloquante).

Formats acceptés : JPG. Garde des images < 400 Ko pour un chargement rapide en 3G.
