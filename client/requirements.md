## Notes
- Using Replit Auth for user authentication.
- API endpoints: `/api/scans` (GET, POST), `/api/analyze` (POST).
- Images will be handled as base64 strings for the MVP analysis to keep it simple, or uploaded to a storage service if provided by backend (assuming base64 for direct AI analysis based on schema).
- Design style: Medical-aesthetic, clean, white/pastel palette, trustworthy.
